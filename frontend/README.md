# 🎨 Frontend - React

Interface do sistema de login.

## 📦 Instalação

```bash
npm install
```

## 🚀 Rodar

```bash
npm start
```

Abre em `http://localhost:3000`

## 📂 Estrutura
src/
├── components/
│   ├── Login.js
│   ├── Register.js
│   └── ...
├── pages/
├── App.js
└── index.js
## 🛠️ Dependências

- react
- react-router-dom
- axios
- tailwindcss
